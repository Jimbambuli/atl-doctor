usage: atl-doctor scan [-f {text,json,html}] [-o FILE] [--atl-src DIR]
                       [--prefix DIR] [--compare-src DIR] [--aosp DIR]
                       [--sdk-int N] [--no-aosp-fetch] [-h] [-q] [-v]
                       APK [APK ...]

Check what the APKs call against what ATL implements. Nothing is started.

Arguments:
  APK                     the apps to scan

Output:
  -f, --format {text,json,html}
                          report format (default: text)
  -o, --output FILE       write to FILE instead of stdout

ATL environment:
  --atl-src DIR           ATL source tree (default: $ATL_DOCTOR_ATL_SRC)
  --prefix DIR            ATL installation prefix (default:
                          $ATL_DOCTOR_PREFIX)
  --compare-src DIR       second ATL source tree (with build*/api-impl.jar) to
                          compare
  --aosp DIR              AOSP source tree (root or frameworks/base) to
                          compare stubs and missing methods with (default:
                          $ATL_DOCTOR_AOSP)

Advanced:
  --sdk-int N             SDK_INT ATL reports (default: the app's minSdk, at
                          least 9)
  --no-aosp-fetch         do not download AOSP source when --aosp is not given
                          (default: fetch once into the cache)

General:
  -h, --help              show this help and exit
  -q, --quiet             only errors on stderr
  -v, --verbose           more messages on stderr
