usage: atl-doctor explain [-d DIR] [--aosp DIR] [--no-aosp-fetch]
                          [--jank-min-frames N] [-h] [-q] [-v]
                          ID

Show all evidence for one finding of a report, found by its ID.

Arguments:
  ID                   full ID, short ID or unique short-ID prefix

Input:
  -d, --dir DIR        capture directory or JSON report

ATL environment:
  --aosp DIR           AOSP source tree (root or frameworks/base; default:
                       $ATL_DOCTOR_AOSP)

Advanced:
  --no-aosp-fetch      do not download AOSP source when --aosp is not given
                       (default: fetch once into the cache)
  --jank-min-frames N  fewest frames a phase needs for a jank finding
                       (default: 30); fewer is noted, not reported

General:
  -h, --help           show this help and exit
  -q, --quiet          only errors on stderr
  -v, --verbose        more messages on stderr
